# EchoTime maintenance and similarity reference update

Date: 2026-10-29. Starting commit: `320b7e65c74be6decef665cea87f56c5dc88ccd2`.

## Scope and evidence

This is a software maintenance and documentation update to the public EchoTime
repository. It preserves the comparison APIs and legacy `tsontology` imports.
The evidence objects are regression tests, mathematical method descriptions,
verified primary references, and reproducible documentation builds. Research
benchmark results and unpublished manuscript repositories are outside this change.

The work addresses three user needs:

1. Reliable numerical comparisons, supported Python versions, and automated tests.
2. A cited comparison of similarity tasks, methods, and existing software, in
   English and Chinese, linked from the README and published documentation.
3. Reusable social copy and reference data that lead readers to runnable examples.

## Execution and acceptance

| Work | Command or evidence | Placement | Failure condition |
| --- | --- | --- | --- |
| Existing behavior | `python -m pytest -q` | Local CPU, isolated environment | Any failing test, recorded separately from new regression failures |
| Numerical fixes | Focused regression tests plus complete existing suite | Local CPU | Invalid inputs silently accepted or documented identities violated |
| Package compatibility | Python 3.10, 3.11, and 3.13 CI; wheel/sdist build | GitHub Actions CPU | Import or installation failure, or missing bundled articles |
| Cited articles | Primary-source URLs and claim/evidence ledger | Read-only source research | Unsupported comparison, unverified performance claim, or ambiguous implementation status |
| Documentation | `python tools/build_knowledge_pages.py --check`; `python tools/release_refresh.py` | Local CPU | Generated pages stale, broken internal targets, or missing reference downloads |
| Publication | Push verified changes to the public repository and inspect CI | GitHub | Remote head differs from the published commit or required checks fail |

No cluster allocation or GPU is required. This update does not run a full
scientific benchmark or produce a performance leaderboard. Synthetic examples
illustrate definitions only. A full experimental matrix, dataset passports, and
SLURM deployment files are therefore not added to this maintenance change.

Articles and social drafts are stored in the repository. Repository publication
does not imply that social drafts have been sent to external platforms.
