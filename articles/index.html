Evidence ledger

The ledger was assembled before drafting. Citation roles describe what each source supports; recommendations in the articles are explicitly presented as a proposed evaluation procedure. Software documentation was checked on 2026-10-29. This is a targeted narrative comparison, with no claim of systematic-review completeness. No library speed or accuracy ranking was measured for these articles.

Claim or object Role Primary source Boundary
DTW aligns ordered observations under admissible paths; local cost and path constraints define the result Definition / Tool tslearn DTW guide A package's transformed similarity score need not equal a canonical raw DTW distance
SBD uses normalized cross-correlation to allow a global shift; k-Shape also defines a centroid procedure Origin / Definition Paparrizos and Gravano, SIGMOD 2015 A global shift differs from local nonlinear time deformation; classification/clustering results do not establish universal retrieval performance
shapeDTW aligns sequences of local descriptors Origin / Definition Zhao and Itti, Pattern Recognition 2018; author preprint Descriptor and neighbourhood settings are part of the method
ADTW adds a penalty for warping Origin / Definition Herrmann and Webb, Pattern Recognition 2023 Parameter scale and tuning protocol matter; no claim of task-independent dominance
Soft-DTW replaces hard path minimization with a smooth aggregation Origin / Definition Cuturi and Blondel, ICML 2017 Differentiability requires a suitable ground cost and positive smoothing parameter
Raw soft-DTW can be negative; corrected divergences have assumptions Limitation / Boundary Blondel, Mensch and Vert, AISTATS 2021 The paper's divergence result is conditional on the ground cost; it does not establish the triangle inequality
